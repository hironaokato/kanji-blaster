# カンジブラスター

漢字を書くほど強く・かっこよくなる、小学生向けのブロック風サバイバーシューター。
ブラウザだけで動きます（iPad 推奨）。

- 小学1〜3年の漢字 440字（学年別漢字配当表）
- 画面に書いた漢字を、書き順データと照合してその場で判定（サーバー・アカウント不要）
- 新しい字・復習・予習を自動で出題（間隔をあけた復習）
- 7つの世界、54種のモンスター＋ボス、ずかん、きがえ
- 2つのゲームモード
  - サバイバー：無限フィールドで敵をなぎ倒す（目的は「生存」「殲滅」「封印石」から選ぶ）
  - 陣地戦：カードで仲間を呼び出し、敵の魔王城をこわす。各エリアの3ステージ目は必ず陣地戦
- 子どもごとの記録と、おうちの人向けの学習記録ページ
- 脅威度：プレイの様子（ダメージ・敵との距離・倒す速さ）を見て敵の強さを自動調整。強くなりすぎても退屈しない
- 地続きのバイオーム：スタート地点から遠くへ歩くと、となりの世界（地面・飾り・空・天気・敵がまるごと変わる）に入る。遠いほど・危険な世界ほど敵が強く、経験値も多い。新しい世界を見つけると宝箱
- 移り変わる世界：朝→昼→夕方→夜の時間変化、天気（雨・雷雨・雪・桜・砂嵐・霧・ほたる など）、森・花畑・遺跡・池の地形、鳥居などの目印
- 漢字を書く場面：クリア後のミッション（6字）、漢字ボックス（書くと鍵＋宝箱）、レベルアップの漢字チャンス、ボスの結界、武器の進化、復活
- アイテム：時の砂時計・結界・スター・風のくつ・巻物・ラッキーポーション・雷だま・おにぎり など
- がんばりポイントと「いっしょにふりかえり」：新しく覚えた字／くり返し練習を分けて記録。おうちの人のハンコ、お金以外のごほうびの約束、認定証
- 漢字バトル（TPS・4対4のCPU戦）：3つの拠点は漢字で表示され、隊長の命令はひらがな。読んで向かうと得点。CPU Lv1〜10（勝つと次が解放）。漢字を書いて「漢字スキル」（マイメカ召喚・流星・結界）や即復活
- マイメカ：マスターした漢字の数でパーツ（胴・足・武器・頭・翼・色）が増える。レゴで作れる設計図を印刷できる
- ほんもののごほうび：学年の漢字の「はんぶん／ぜんぶマスター」と、もぎしけん（10級・9級・8級）合格をふしめに、おうちの人が決めたごほうび（レゴなど）を渡す。写真で記録
- 主人公の表情（うれしい・痛い・本気・ピンチ・びっくり）

## 遊び方
`index.html` を GitHub Pages などで公開し、iPad の Safari で開いて「共有 → ホーム画面に追加」するとアプリのように使えます。
記録はそれぞれのブラウザ内（localStorage）に保存されます。
